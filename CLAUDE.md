# CLAUDE.md

> ⚠️ **Bu repo'nun ajan kuralları [`AGENTS.md`](AGENTS.md) dosyasındadır.**
>
> Herhangi bir iş yapmadan önce `AGENTS.md`'yi oku — **zorunludur.**

Kurallar tek dosyada tutuluyor ki Claude Code ve Codex aynı şeyi okusun; iki ajan dosyası zamanla birbirinden sapmasın.

`AGENTS.md` içinde ne var:

- **Oturum protokolü** — Notion `📓 Oturum Kaydı`'nda oturum başında çakışma kontrolü, oturum sonunda kayıt güncelleme. İki kişinin ajanları çakışmasın diye bu zorunlu.
- **Kesin kurallar** — branch adı, commit formatı, PR başlığı, DW-ID zorunluluğu, sır politikası
- **Kod tarzı** ve **commit/push** davranışı
- **Notion referansı** — database ve data source ID'leri

İnsan kuralları için [`CONTRIBUTING.md`](CONTRIBUTING.md).
